# Audio (not committed)

The app plays two local files from this folder if they exist:

| File | When |
|---|---|
| `gigachad.mp3` | Loops while the headline score is 8.0 or higher; pauses (and later resumes) below it |
| `vine-boom.mp3` | Once per raised eyebrow, in camera mode |

They are copyrighted clips, so they are git-ignored. Drop your own copies here
with these exact names. Without them the app works silently.
